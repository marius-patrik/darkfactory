# Archived

DarkFactory is retired as a standalone product. Its useful GitHub control-plane logic, deterministic planning/orchestration, repository policy, managed-repository synchronization, enforcement, workflow automation, and review/recovery mechanisms are source material for absorption into DSH Stack.

The DSH Stack rewrite must not retain DarkFactory's separate Agent OS control-plane architecture. Shared agent orchestration, state, credentials, sessions, repositories, projects, jobs and UI belong to DSH Stack/DSH and its canonical capabilities.

Useful behavior should be ported into the Stack project/planning, repository, automation, job/orchestration and policy capabilities. Repository-local policy concepts should be reconciled with DSH Stack configuration/profile/bundle semantics rather than copied as a second configuration system.

This repository is no longer an active implementation target.
